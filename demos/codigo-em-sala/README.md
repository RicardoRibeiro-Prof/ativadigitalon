# Código em Sala

Protótipo de blog educacional sobre programação, banco de dados, redes e jogos digitais.

## Conteúdo inicial

- página inicial responsiva;
- busca e filtros por categoria;
- três artigos completos;
- páginas Sobre, Contato e Política de Privacidade;
- metadados básicos de SEO, `robots.txt` e `sitemap.xml`;
- área reservada para futura integração com Google AdSense.

## Teste local

Abra `index.html` no navegador ou sirva a pasta com um servidor HTTP estático.

## AdSense

O código do AdSense não foi inserido porque exige o identificador real da conta aprovada. Depois da aprovação, adicione o script oficial e substitua as áreas marcadas como publicidade.
