CRUD: entenda as quatro operações fundamentais

8 minutos de leituraPublicado em 22 de agosto de 2026

CRUD é a sigla usada para representar as quatro ações básicas realizadas com dados: criar, consultar, atualizar e excluir. Quase todo sistema utiliza essas operações, desde uma agenda escolar até um aplicativo de delivery.

CRUD significa: Create, Read, Update e Delete. Em SQL, normalmente usamos INSERT, SELECT, UPDATE e DELETE.

1. Create: criar um registro

Imagine uma tabela chamada alunos. Para cadastrar uma pessoa, usamos o comando INSERT:

INSERT INTO alunos (nome, turma)
VALUES ('Marina', '1ª Série A');

2. Read: consultar registros

O SELECT lê os dados armazenados. O asterisco solicita todas as colunas:

SELECT * FROM alunos;

Para encontrar somente uma turma, acrescentamos uma condição:

SELECT * FROM alunos
WHERE turma = '1ª Série A';

3. Update: atualizar um registro

O UPDATE altera informações existentes. A condição WHERE é essencial para indicar qual registro será modificado.

UPDATE alunos
SET turma = '1ª Série B'
WHERE id = 1;

4. Delete: excluir um registro

O DELETE remove dados. Sem WHERE, todos os registros da tabela podem ser excluídos.

DELETE FROM alunos
WHERE id = 1;

Pratique

Crie uma tabela chamada livros com id, título, autor e ano. Depois, escreva quatro comandos: cadastrar um livro, consultar todos, alterar o ano do livro de id 1 e excluir esse mesmo livro.

O que realmente importa

Não memorize apenas os comandos. Pense sempre na ação que o usuário realiza: cadastrar corresponde ao INSERT, visualizar ao SELECT, editar ao UPDATE e remover ao DELETE. Essa associação torna o CRUD muito mais fácil de compreender.
