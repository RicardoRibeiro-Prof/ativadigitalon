Estrutura FOR em C#: aprenda passo a passo

7 minutos de leitura22 de agosto de 2026

A estrutura FOR repete um bloco de código quando sabemos quantas vezes a ação deve acontecer. Em vez de escrever a mesma instrução dez vezes, criamos uma repetição controlada.

O primeiro exemplo

for (int numero = 1; numero <= 10; numero++)
{
    Console.WriteLine(numero);
}

Entendendo cada parte

  1. int numero = 1: cria a variável e define o valor inicial.
  2. numero <= 10: determina até quando a repetição continua.
  3. numero++: aumenta o valor em uma unidade após cada volta.
  4. Console.WriteLine(numero): mostra o valor atual.
Se você escrever Console.WriteLine("numero"), o programa exibirá a palavra “numero”. Sem aspas, ele mostra o valor da variável.

Um exemplo com total

double total = 0;

for (int item = 1; item <= 3; item++)
{
    Console.Write("Digite o valor: ");
    double valor = Convert.ToDouble(Console.ReadLine());
    total += valor;
}

Console.WriteLine("Total: R$ " + total);

A conversão é necessária porque o texto digitado pelo teclado chega ao programa como texto, mesmo quando a pessoa digita apenas números.

Pratique

Faça um programa que solicite cinco notas, some os valores e mostre a média final. Antes de programar, identifique o valor inicial, a condição e o incremento do FOR.
